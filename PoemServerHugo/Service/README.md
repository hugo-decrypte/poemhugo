## 📁 PoemServer Service - README

This folder contains everything needed to run the **PoemServer** as a **Windows service**, using [WinSW](https://github.com/winsw/winsw).

### 📦 Folder contents

| Name                       | Description                                                                                                                      |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `PoemServerService.bat`    | 💡 **Main control script** – install/start or stop/uninstall the service. Use this to manage the service easily.                 |
| `Start/StopService.bat`    | 💡 **Start/Stop scripts** – install/start or stop/uninstall the service.                                                         |
| `PoemServer?.xml`          | 🧾 **WinSW configuration** – Defines how the service behaves (name, description, log options, command to run).                   |
| `WinSW.exe`                | ⚙️ **WinSW executable** – Turns the `PoemServer.ps1` script into a Windows service via `PoemServerservice.xml`.                  |
| `/Instances/`              | 📁 **Service logs directory** – Contains auto-rotating logs generated by the service (output and errors).                        |
| `/Instances/log/`          | 📁 **Service logs directory** – Contains auto-rotating logs generated by the service (output and errors).                        |

---

### ▶️ How to use

1. **Double-click** `StartService.bat` to install and start the service
2. **Double-click** `StartService.bat` to stop and uninstall it
3. Logs will be written in the `Instances/log` folder.
